# 🌸 Flower Classification Using CNN

## 1. Project Overview
This project focuses on classifying flower images using a Convolutional Neural Network (CNN).

CNN is a Deep Learning algorithm mainly used for image classification and image recognition. It automatically extracts features from images and predicts the correct category.

## 2. Objective
The main objective of this project is to build a CNN model that can identify and classify different types of flowers.

## 3. Dataset
The dataset contains images of three different flower categories:

- Daisy
- Dandelion
- Rose

## 4. Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-learn

## 5. CNN Architecture

The CNN model consists of the following layers:

1. **Convolutional Layer:** Extracts important features from images.
2. **ReLU Activation:** Introduces non-linearity.
3. **Max Pooling Layer:** Reduces image dimensions.
4. **Flatten Layer:** Converts feature maps into a one-dimensional array.
5. **Dense Layer:** Performs classification.
6. **Softmax Activation:** Predicts the flower category.

## 6. Project Workflow

1. Import required libraries.
2. Load the flower dataset.
3. Preprocess and resize images.
4. Split the dataset into training and testing sets.
5. Build the CNN Sequential model.
6. Compile the model.
7. Train the model.
8. Evaluate model performance.
9. Display accuracy and loss graphs.
10. Generate a confusion matrix and classification report.

## 7. Model Evaluation

The model performance is evaluated using:

- Accuracy
- Loss
- Confusion Matrix
- Classification Report

## 8. Conclusion

This project demonstrates how Convolutional Neural Networks can be used for image classification. The CNN model learns image features and classifies flower images into their respective categories.
